# Код узлов n8n проката (вебхуки `/prokat`, `/prokat-foto` и `/prokat-owner`)

Копия кода из автоматизаций n8n «Кабинет проката — Финансист (пункты, деньги)» и «Кабинет проката — Фото инструментов по пунктам», чтобы изменения были видны в pull request и проверялись тестом `test/prokat.js`.
Живой код хранится в n8n: после правки здесь его нужно перенести в соответствующий узел и опубликовать.

| Файл | Узел n8n |

Таблицы n8n:
- «Склад» (`h51dIhwmJf4gOUSZ`): движения. `instrument` — вид, `izmenenie` — плюс/минус, `sostoyanie` — `сломан`, `в ремонте`, `починен`, `на запчасти` (или `фото` — отметка, что у вида новое фото), `zapchast` — название запчасти (тогда это движение запчасти, а не аппарата), `oid` — номер записи от приложения против повторов.
- «Прокат — фото склада» (`NM8yg4AJHv24ma8e`): фото вида, маленький JPEG до 60 000 знаков. Узел «Фото склада» читает только строку нужного вида и только для `stock_photo_get`.

Действия: `stock`, `stock_move` (`state` или `part`), `stock_state` (`from` → `to`), `stock_photo`, `stock_photo_get`. Строки без состояния считаются «починен» (так записывал старый экран).

Фото-история: старые фото — таблица «Фото по точкам» (`kBSbnRBcHvK9xC3E`, пункт, инструмент, дата из таблицы проката; у фото без названия имя берётся из той же строки таблицы на этом пункте), новые — фото объездов из «Визиты» (`OOnwv2BtyartGGh7`). Миниатюры отдаёт Google Drive (`thumbnailLink`).

Подписи фото: таблица «Прокат — подписи фото» (`d55qgy4tlo4sTlQI`: `drive_file_id`, `tochka`, `instrument`, `avtor`, `data`). Последняя подпись фото важнее названия из таблицы проката. 26.10.2026 ИИ подписал 44 фото без названия по типу инструмента (фото из одной строки таблицы — один аппарат). Кнопка «Это другой инструмент» (действие `relabel`) добавляет новую подпись.
