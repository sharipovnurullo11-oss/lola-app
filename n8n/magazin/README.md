# Код узлов n8n «Кабинет — учёт магазина» (вебхук `/magazin`)

Копия кода из автоматизации n8n «Кабинет — учёт магазина» (магазин Шамсуло, колхоз «Россия»), чтобы изменения были видны в pull request и проверялись тестом `test/shop.js`.
Живой код хранится в n8n: после правки здесь его нужно перенести в соответствующий узел и опубликовать.
Узла «Кабинет» здесь нет: в нём код кабинета, а коды кабинетов в репозиторий не кладём.

| Файл | Узел n8n |
|---|---|
| `reshit.js` | «Решить» — товары, остатки, приём, продажа, долги, сдача кассы: `sdacha` (наличные должно / сдал / разница, итог смены по способам оплаты — JSON в `ssylka` строки `tip: 'sdacha'`) `sdacha_ok` (подтверждение смены руководителем, строка `tip: 'sdacha_ok'`, `ssylka` = номер сдачи) и `kassa` (внесли / взяли наличные в смене: строка `tip: 'kassa'`, `oplata` = `in` / `out`, `pokupatel` = чья касса; учитывается в «должно быть» при сдаче, отменяется через `void`; продавцу в «Кабинете» разрешено) |
| `analiz.js` | «Анализ и пересчёт» — прибыль, залежавшийся товар, заказ, пересчёт |
| `dlya-prodavca.js` | «Для продавца» — что видят продавец и кладовщик |
| `vozvrat.js` | «Возврат» (после «Анализ и пересчёт», перед «Для продавца») — возврат по чеку: `chek_get` (чек по номеру или последним 6+ знакам, сколько уже вернули) и `vozvrat` (часть позиций по цене продажи; строки продажи с минусом, номер чека возврата = исходный + `r` + 6 знаков). Продавцу в «Кабинете» разрешены `chek_get` и `vozvrat` |
| `shtrihkody.js` | «Штрихкоды» (после «Для продавца», перед «Поиск по фото?»; узел «Ответ» берёт ответ отсюда) — заводские штрихкоды товара: у каждого товара `bar`, привязка `bind_barcode` / `unbind_barcode` вместе с `list` (руководитель и кладовщик). Строки журнала `tip: 'shtrih'` / `'shtrih_del'`, штрихкод в `ssylka` |
| `foto-zapros.txt` | тело запроса узла «ИИ: товар по фото» (gpt-4o-mini) |
| `foto-razobrat.js` | «Разобрать ответ по фото» |

Единица товара хранится в столбце `oplata` строки товара (`sht`, `m`, `kg`, `g`, `rulon`), «сколько единиц в одной штуке» — в столбце `summa`.

Уведомления хозяину: после «Записать» узел «Расход продавца?» пропускает строки `rashod` и `sdacha` сотрудника в «Push владельцу» (`/push/send`, виды `rashod` и `sdacha`; текст собирает `push.js`).

Утреннее напоминание о товаре (№295): автоматизация «Магазин — утром на телефон: заканчивается товар» (`QoqAvvl9V7eIpfUA`) каждый день в 8:13 по Душанбе берёт `stats` из `/magazin` для одобренных кабинетов (коды — из заявок) и, если в списке «Заказать у поставщика» есть товары (остаток не выше минимума), шлёт на `/push/send` `kind: 'shop_low'` — сколько товаров и первые три с остатком и минимумом. Минимумы задаются в «Анализ» → «Заказ».
